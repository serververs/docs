## Overview

This guide explains how to set up email for your domain using Serververse.

Once configured, you will be able to:

- send and receive emails
- use apps like Gmail, Outlook, Apple Mail, or Thunderbird
- benefit from automatic setup in supported clients

# 1. How Email Works

Your email setup includes three parts:

### DNS Records

Tell the internet where your email is hosted

### Mailboxes

Your actual email accounts Example:

```text
info@yourdomain.com
support@yourdomain.com
```

### Mail Servers

Used by apps to send and receive email

Serververse uses a **central mail server**:

```text
mail.serververs.com
```

# 2. Required DNS Records

Add these records in your domain’s DNS panel.

## MX Record

```text
Type: MX
Host: @
Value: mail.serververs.com
Priority: 10
```

## SPF Record

```text
Type: TXT
Host: @
Value: v=spf1 a mx ip4:IP_ADDRESS include:yourdomain.com ~all
```

Replace `YOUR_SERVER_IP` with your server IP.

## DKIM Record

1. Open your Serververse panel
2. Go to DKIM Manager
3. Copy your DKIM key
4. Add:

```text
Type: TXT
Host: default._domainkey
Value: (your DKIM key)
```

<Warning>
  Remove Double Quotes (") from whole text and then use it in DNS.
</Warning>

## DMARC Record

```text
Type: TXT
Host: _dmarc
Value: v=DMARC1; p=none; rua=mailto:postmaster@yourdomain.com
```

## 4. SMTP & IMAP Configuration

To send and receive emails through applications like Outlook, Apple Mail, or Gmail, use the following configuration:

<Tabs>
  <Tab title="Incoming Mail (IMAP/POP)">
    **IMAP Host:** `imap.serververs.com` \
    **IMAP Port:** `993` (SSL/TLS)\
    OR\
    **POP Host:** `pop.serververs.com` \
    **POP Port:** `995` (SSL/TLS)
  </Tab>
  <Tab title="Outgoing Mail (SMTP)">
    **SMTP Host:** `smtp.serververs.com` \
    **SMTP Port:** `465` (SSL/TLS) or `587` (STARTTLS)
  </Tab>
</Tabs>

# 5. Autodiscover Email Config (Recommended)

Most modern email apps can configure everything automatically.\
You only need:

```text
Email address
Password
```

## To enable automatic setup

Add these DNS records:

```text
autodiscover  CNAME  autodiscover.serververs.com
autoconfig    CNAME  autoconfig.serververs.com
```

# 8. Common Issues

### Emails going to spam

Check SPF, DKIM, and DMARC records

### Cannot connect to mailbox

Verify:

- server name
- ports
- password

### SSL or connection warnings

Make sure you are using:

```text
mail.serververs.com
```

# 9. Best Practices

- Use separate mailboxes for different roles
- Keep DNS records updated
- Avoid sending bulk emails from your main mailbox
- Always use secure ports (993 / 465 / 587)
